A minimal LLM inference serving simulator written in Python. It implements a request scheduler with continuous batching on top of a deterministic simulation core, so scheduling behavior can be reproduced exactly and compared across policies. The project also includes hands on vLLM benchmarking to ground the simulation in real serving behavior.
